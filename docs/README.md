# docs/

The cookbook's user pages, the Cookbook tab of
<https://looper.goaly.ai/wiki/cookbook.html>.

| File | What it holds |
|---|---|
| `index.md` | The tab's first page, "The cookbook": when to use the cookbook over the SDK, a map of the pages, and how an RL task is put together |
| `message-formatting.md` | "Message formatting": each model's message formatter, every call, tool calls, thinking and what a formatter refuses |
| `supervised-learning.md` | "Supervised learning": conversations to datums, and the SFT loop with its config |
| `reinforcement-learning.md` | "Reinforcement learning": tasks and the dataset, the RL loop, groups, the config and what a step reports |
| `episode-sessions.md` | "Episode sessions": a task as a config, an episode run by hand with `AgentSession`, its two token budgets and why it ends, the episode and its datum, a harness and a session of your own |
| `environments.md` | "Environments": the bash and coding environments, a model's tool calls run by hand, and an environment of your own |
| `sandboxes.md` | "Sandboxes": the local and Docker sandboxes, a command's result, and a sandbox of your own |
| `verifiers.md` | "Verifiers": `FinalNumber`, `CodeTestsVerifier`, and a verifier of your own |
| `evaluation.md` | "Evaluation": held-out tasks in a loop, `evaluate` on any sampler, a checkpoint's evaluation and reading the numbers |
| `recipes.md` | "Recipes": each recipe, its command and its data. The `code_rl` recipe's page is its own README, `looper_cookbook/recipes/code_rl/README.md` |
