# tutorials/

The tutorials as Jupyter notebooks, the Tutorials tab of
<https://looper.goaly.ai/wiki/tutorials.html>. Start at `index.md`: what you
need, then each tutorial by level, with what it teaches and what to read
first.

A notebook's number orders the tutorials and its first digit groups them:
1 the basics, with the SDK alone; 2 core concepts; 3 the cookbook's loops.
Each holds the outputs of a run against Looper, so you can read it without
running it.
